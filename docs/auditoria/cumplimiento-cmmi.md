# Cumplimiento CMMI

Mapeo de áreas de proceso de CMMI contra la documentación y prácticas de Certy.

## Gestión de Requisitos (REQM)

| Práctica | Implementación |
|----------|---------------|
| Obtener entendimiento de requisitos | Historias de usuario con criterios de aceptación |
| Obtener compromiso con requisitos | Project Charter |
| Gestionar cambios de requisitos | Trazabilidad documentada |
| Mantener trazabilidad bidireccional | Matriz de trazabilidad |
| Identificar inconsistencias | Revisiones periódicas |

## Planificación de Proyecto (PP)

| Práctica | Implementación |
|----------|---------------|
| Estimar alcance | Project Charter |
| Establecer presupuesto y cronograma | Jira / Scrum |
| Identificar riesgos | Matriz de riesgos |
| Planificar recursos | Documentación de infraestructura |

## Aseguramiento de Calidad (PPQA)

| Práctica | Implementación |
|----------|---------------|
| Evaluar procesos | SonarQube + checklist SDLC |
| Evaluar productos | Pruebas automatizadas |
| Comunicar no conformidades | Reportes de calidad |
| Registrar hallazgos | Auditoría documentada |

## Gestión de Configuración (CM)

| Práctica | Implementación |
|----------|---------------|
| Identificar items de configuración | Git + versionado semántico |
| Establecer línea base | Releases etiquetadas |
| Controlar cambios | GitFlow + code review |
| Reportar estado | Changelog + release notes |

## Medición y Análisis (MA)

| Práctica | Implementación |
|----------|---------------|
| Establecer objetivos de medición | Cobertura de pruebas, SonarQube |
| Especificar medidas | Reportes de cobertura |
| Recolectar y almacenar datos | SonarQube + Locust + pytest |
| Analizar e interpretar | Dashboards de calidad |
| Comunicar resultados | Reportes en anexos |
