# Checklist de Auditoría SDLC

## 1. Planificación y Requisitos

- [ ] Catálogo formal de requisitos funcionales
- [ ] Catálogo formal de requisitos no funcionales
- [ ] Historias de usuario con criterios de aceptación
- [ ] Matriz de trazabilidad requisitos → código
- [ ] Project Charter firmado

## 2. Diseño y Arquitectura

- [ ] Diagrama C4 de contexto
- [ ] Diagrama C4 de contenedores
- [ ] Diagrama C4 de componentes
- [ ] Diagrama de base de datos (ER)
- [ ] Decisiones de arquitectura documentadas (ADR)
- [ ] Diagramas BPMN de procesos críticos

## 3. Desarrollo

- [ ] Convenciones de código documentadas
- [ ] Estrategia de ramas (GitFlow)
- [ ] Política de commits convencionales
- [ ] Guía de code review
- [ ] Gestión de dependencias documentada

## 4. Pruebas

- [ ] Estrategia de pruebas documentada
- [ ] Pruebas unitarias implementadas y documentadas
- [ ] Pruebas de integración implementadas y documentadas
- [ ] Pruebas E2E implementadas y documentadas
- [ ] Pruebas de carga (Locust) documentadas
- [ ] Reportes de cobertura disponibles

## 5. Despliegue y Operación

- [ ] Guía de instalación completa
- [ ] Docker y docker-compose documentados
- [ ] Variables de entorno documentadas
- [ ] Pipeline CI/CD documentado (GitHub Actions / Jenkins)
- [ ] Procedimiento de despliegue a producción
- [ ] Manual de operación

## 6. Seguridad

- [ ] Esquema JWT documentado
- [ ] Flujo OAuth documentado
- [ ] Matriz de permisos y roles
- [ ] Análisis de amenazas
- [ ] Reporte Bandit de seguridad estática
- [ ] Buenas prácticas de seguridad documentadas

## 7. Mantenimiento

- [ ] Política de versionado semántico
- [ ] Changelog actualizado
- [ ] Procedimiento de respaldo
- [ ] Procedimiento de restauración
- [ ] Procedimiento de actualización

## 8. Documentación Técnica

- [ ] README completo
- [ ] QUICK_START
- [ ] Documentación OpenAPI / Swagger
- [ ] Manuales de usuario por rol
- [ ] Documentación técnica del código

## 9. Proceso Scrum / Jira

- [ ] Gestión de backlog documentada
- [ ] Sprints documentados
- [ ] Evidencias de reuniones (daily, sprint review, retro)

## 10. Evidencias Generales

- [ ] Reportes de SonarQube
- [ ] Reportes de cobertura de pruebas
- [ ] Evidencias de seguridad (Bandit, pip-audit)
- [ ] Releases y versiones publicadas
- [ ] Registro de commits convencionales
