# Manual del Participante

## Acceso al Sistema

1. Ir a la URL del sistema
2. Hacer clic en "Iniciar sesión" o "Registrarse"
3. Si ya tienes cuenta: ingresar email y contraseña
4. Si no tienes cuenta: completar registro con email, nombre y contraseña
5. También puedes ingresar con Google

## Visualizar Certificados

1. Iniciar sesión en el sistema
2. En el menú lateral, hacer clic en "Certificados"
3. Verás la lista de tus certificados emitidos
4. Cada certificado muestra: evento, fecha de emisión, código de verificación
5. Hacer clic en un certificado para ver el detalle

## Descargar Certificado

1. Desde la lista o el detalle del certificado
2. Hacer clic en "Descargar PDF"
3. El PDF se descargará con:
    - Nombre del participante
    - Datos del evento
    - Código QR de verificación
    - Firma del instructor

## Verificar un Certificado

Cada certificado tiene un código único de verificación. Para verificar:

1. Ir a la página de verificación pública
2. Ingresar el código de verificación
3. El sistema mostrará los datos del certificado si es válido

## Perfil

- Tu información de perfil (nombre, email) se muestra en el sidebar
- No puedes modificar tu rol (asignado por el administrador)
