# Manual del Administrador

## Acceso

1. Ingresar a la URL del sistema
2. Hacer clic en "Iniciar sesión"
3. Ingresar credenciales de administrador (email + contraseña)
4. También disponible: "Iniciar sesión con Google"

## Funcionalidades Exclusivas

### Gestión de Usuarios

- Acceder al admin de Django: `https://dominio/admin/`
- Crear, editar y desactivar usuarios del sistema
- Asignar roles (admin, coordinador, participante)

### Auditoría

- En la interfaz principal, navegar a la sección de auditoría
- Visualizar registro de acciones: generación de certificados, entregas, inicios de sesión
- Filtrar por tipo de acción y usuario
- Ver dirección IP y detalles de cada acción

### Exportación

- Desde la lista de certificados, usar el botón "Exportar"
- Seleccionar formato (CSV o Excel)
- Los datos exportados incluyen: participante, evento, estado, código de verificación

## Dashboard

Panel principal con tarjetas de:
- Total de certificados emitidos
- Eventos activos
- Participantes registrados
- Instructores registrados

Accesos directos a: Certificados, Eventos, Participantes, Generación Masiva
